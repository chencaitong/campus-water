## 功能

- **控制**：查看一卡通钱包余额，在按钮内直接显示用水数字码，支持重新获取和停止使用。
- **记录**：同步消费金额与交易时间，按学校交易详情识别用水记录，支持查看全部消费核对；账单按账号在本机隔离保存。
- **课表**：原生周课表和每日课程，支持前后周、指定周次、选中日期及课程详情。
- **同步策略**：余额与账单每小时自动同步；课表按 UTC+8 自然日每天自动同步一次；均提供手动刷新。应用关闭后不运行常驻同步服务，下次打开时检查是否到期。
- **课前通知**：根据已同步课表安排上课前 30 分钟的普通通知，显示科目、上课时间和地点；支持提醒开关、时间编辑和测试通知。
- **交互**：悬浮底栏、蓝色水滴图标；短距离左右滑动约 32 dp 切换相邻一页，每次手势最多一页，动画可被下一次手势接管；两侧保留系统返回手势区域。

课前时间以大课开始节次配置：默认第 1–2 节 08:00、第 3–4 节 10:00、第 5–6 节 14:00。请依据自己的实际作息修改；没有填写开始时间的节次不会安排提醒。

## 使用方式

1. 在“我的”中进入学校官方统一认证，使用本人学校账号登录。
2. 返回“控制”查看钱包或获取用水码；认证失效时重新登录。
3. 在“课表”中检查真实课程，必要时点击“手动刷新”。
4. 打开“课前提醒设置”，核对时间并允许系统通知，可发送测试通知。

普通定时通知不要求“准时闹钟”权限，但省电、强行停止应用等系统行为可能延迟或停止通知，**不能保证恰好提前 30 分钟到达**。学校临时调课后请刷新；未同步的课程不会提醒。

## 登录与适配限制

目前仅连接上述学校的统一认证、一卡通及课表服务，不是跨学校通用客户端。今日校园自身的手机号、微信、QQ 登录尚未接入本应用；打开其他应用不等于在本应用完成登录。未验证所有学校账号或设备组合。

## 源码与构建

本应用使用 Java 原生界面、Android 系统 API 和必要的学校网页逻辑，无额外应用运行时依赖。

```text
AndroidManifest.xml
src/cn/local/campuswater/   应用代码
res/                       界面、图标和网络策略
scripts/build.py           可移植构建脚本
tests/                     仅含合成数据的回归测试
```

需要 Python 3、JDK 21、Android SDK Platform 35 和 Build Tools 35.0.0。设置 `JAVA_HOME` 与 `ANDROID_SDK_ROOT` 后，在仓库根目录执行：

```sh
python scripts/build.py
```

默认生成对齐后的未签名 APK。自行签名时通过参数传入仓库外的密钥文件，通过环境变量提供密码：

```sh
python scripts/build.py --keystore /path/outside/repository/release.jks --alias release --store-pass-env KEYSTORE_PASSWORD
```

不要把真实密码写进命令示例、源码或仓库。自行构建使用不同签名时，通常无法覆盖安装已发布 APK；请自行处理数据备份与卸载影响。发布者保管的现有签名私钥不随源码分发。

账单脚本回归可运行 `node tests/test_account_sync.cjs`；Java 策略测试需先构建，并提供独立的 `org.json` 测试 JAR，见 `tests/README.md`。
